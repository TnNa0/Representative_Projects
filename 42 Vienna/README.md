This directory contains all the projects i conducted at 42 Vienna.
They are C-based and focus from basic algorithms, to smaller project implementations with the goal to understand the basics of programming logic.

Project Summary:

printf
Reimplement the standard C printf() function. Focuses on variadic functions, format parsing, and formatted output.

get next line
Implement a function that reads a file line by line. Introduces file descriptors, static variables, dynamic memory allocation, and buffered reading.

minitalk
Develop a client-server communication program using UNIX signals. Explores interprocess communication, bitwise operations, and signal handling.

fract-ol
Create an interactive fractal visualizer. Applies complex numbers, iterative mathematical algorithms, graphical rendering (MiniLibX), and event handling.

philosophers
Simulate the Dining Philosophers problem. Introduces multithreading, mutexes, synchronization, race conditions, and deadlock prevention.
